Objects in JavaScript

Open the console to see the output of the JavaScript code examples.

Objects in JavaScript are collections of key-value pairs. They can contain properties and methods. Here's an example of an object:

        let obj = { 
            name: "John",
            age: 30,
            salary : 50000, 
            languages: ["JavaScript"], 
            isAdmin : false,
        }

You can access object properties using dot notation or bracket notation. For example:

        console.log(obj.name); // Output: John
        console.log(obj["age"]); // Output: 30

You can also add new properties to an object or modify existing ones. For example:

        obj.city = "New York"; // Adding a new property 
        obj.age = 31; // Modifying an existing property
        console.log(obj);
