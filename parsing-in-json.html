Parsing JSON in JavaScript

To parse a JSON string in JavaScript, you can use the built-in JSON.parse() method. This method takes a JSON string as input and returns the corresponding JavaScript object.

Example

const jsonString = '{"name": "John", "age": 30, "city": "New York"}';
const jsonObject = JSON.parse(jsonString);
console.log(jsonObject.name); // Output: John
console.log(jsonObject.age);  // Output: 30
console.log(jsonObject.city); // Output: New York

In this example, we have a JSON string that represents an object with three properties: name, age, and city. We use JSON.parse() to convert the JSON string into a JavaScript object, which we can then access using dot notation.

Handling Errors

If the JSON string is not properly formatted, JSON.parse() will throw a SyntaxError. To handle this, you can use a try...catch block:

const invalidJsonString = '{"name": "John", "age": 30, "city": "New York"'; // Missing closing brace
try {    const jsonObject = JSON.parse(invalidJsonString);
} catch (error) {    console.error('Error parsing JSON:', error);
}

In this example, the JSON string is missing a closing brace, which will cause JSON.parse() to throw a SyntaxError. The error is caught in the catch block, and an error message is logged to the console.
